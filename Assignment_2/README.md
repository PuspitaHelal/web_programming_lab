# To-Do List App
### Developed by Puspita Helal
This project is **open-source** and free to use! Feel free to modify and improve it. 🚀
A simple **To-Do List App** built with **HTML, CSS, and JavaScript**. This app allows users to add, mark as complete, and delete tasks efficiently.

## 🚀 Features
- **Add new tasks** to the to-do list.
- **Click on tasks** to mark them as completed (strikethrough effect).
- **Delete tasks** with a red button.
- **Preloaded example tasks** when the page loads.
- **Simple and clean UI** with minimalistic design.

## 🛠️ Technologies Used
- **HTML** – For the structure.
- **CSS** – For styling and layout.
- **JavaScript** – For dynamic interactions and state management.

## 📌 How to Use
1. Open `index.html` in any web browser.
2. Type a task in the input field.
3. Click the **Add** button to add the task.
4. Click on a task to **toggle completion** (cross out text).
5. Click the **Delete** button to remove a task.
